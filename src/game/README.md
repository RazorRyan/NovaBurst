# Game Module

This folder is reserved for NovaBurst gameplay code that will be added in later prompts.

Use the subfolders here for:

- `components`: Skia-driven gameplay presentation
- `systems`: simulation, spawning, collisions, and tuning
- `hooks`: gameplay lifecycle helpers
- `state`: lightweight shared game state
- `types`: gameplay contracts
- `utils`: math and helper functions

Prompt 01 intentionally leaves gameplay implementation out of scope.
